# E-Commerce-Customer-Segmentation
# E-Commerce Sales Analysis and Customer Segmentation

## Project Overview

This project analyzes e-commerce transaction data to understand sales performance and customer purchasing behavior.

The project uses Exploratory Data Analysis (EDA), RFM Analysis, and K-Means Clustering to identify meaningful customer segments and generate actionable business insights.

## Objectives

- Analyze e-commerce sales performance
- Identify top products and countries
- Analyze monthly and weekly sales trends
- Perform RFM customer analysis
- Apply K-Means clustering
- Identify customer segments
- Develop a business dashboard
- Generate business recommendations

## Technologies Used

## Dataset

This project uses the Online Retail dataset for analysis.

The original dataset is not included in this repository because of its large file size.

The dataset was used locally for data cleaning, exploratory data analysis,
RFM analysis, and K-Means customer segmentation.

### Dataset Columns

The dataset contains the following columns:

- InvoiceNo
- StockCode
- Description
- Quantity
- InvoiceDate
- UnitPrice
- CustomerID
- Country

## Customer Segmentation

The project identifies customer groups based on:

- Recency
- Frequency
- Monetary Value

The resulting segments include:

- Champions
- New Customers
- Potential Loyalists
- Lost Customers

## Business Insights

The analysis helps identify high-value customers, inactive customers, important markets, and seasonal sales patterns.

These insights can support customer retention, targeted marketing, re-engagement campaigns, and revenue optimization.
